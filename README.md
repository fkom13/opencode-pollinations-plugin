## 🚀 Key Features (v6.1 Beta)

- **🌍 Free Universe**: Access generic models (`openai`, `mistral`, `gemini`) for **FREE**, unlimited time.
- **🛡️ Robust Quota System (NEW)**: Local "Ledger" technology (`~/.pollinations/usage_history.json`) ensures 100% accurate usage tracking, zero lag, and no wallet drain.
- **🚀 Pro Mode**: Connect your API Key for Premium Models (`claude-3-5-sonnet`, `gpt-4o`, `deepseek-r1`).
- **🔐 Limited Key Support**: "Generation Only" keys are fully supported (perfect for sharing keys securely).
- **🔇 Stealth Mode**: Notifications are minimized to respect your focus.

## 🚀 Getting Started

### 1. Installation

```bash
# Recommended: Auto-Setup
npm install -g opencode-pollinations-plugin
npx opencode-pollinations-plugin
```

### 2. Configuration

```bash
/connect
```
Choose "pollinations" and enter your key (optional).
