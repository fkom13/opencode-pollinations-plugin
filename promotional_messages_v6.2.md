- Bypasses the need for multiple API subscriptions by centralizing on one highly generous free-tier API.
- Native Support for BYOK (Bring Your Own Key) for heavy users.
- Comprehensive local security audit (patched Path Traversal & Command Injection vulnerabilities for safe local file manipulation by the LLM).
- Full Test Suite cleaned up and available for contributors.

I’m sharing this because I’m looking for honest feedback, stress-testing, and maybe some contributors who want to help expand what OpenCode agents can do natively without breaking the bank. I think the dynamic Tool generation mapping from an external endpoint is a really fun architectural pattern.
